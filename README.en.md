# WalkGo

WalkGo is a Flutter application designed to solve the problem of "not being able to accurately record steps during exercise." When you are engaged in activities that are not easily detected by your phone, or when you simply forget to carry it, WalkGo can help you log these missed steps. It provides a powerful and easy-to-use solution to make your health data more complete.

## Key Features

- **Automatic Stepping**: Set your desired number of steps and time interval, and WalkGo will automatically and stably write step data to your health app in the background.
- **Manual Mode**: Need to add steps immediately? With just one click, you can manually write your set number of steps.
- **Smart Settings**:
  - **Random Offset**: Allows the number of steps written each time to fluctuate randomly within a small range, making the data look more natural.
  - **Auto Pause**: Set a step limit, and the service will automatically pause when the target is reached, preventing the generation of excessive, unnecessary data.
- **Highly Customizable**: You can freely adjust the base number of steps per write, the random offset range, the time interval, and the auto-pause limit.
- **Multi-language**: Built-in support for multiple languages, including Traditional Chinese and English.
- **Dark Mode**: Supports both light and dark modes for a comfortable visual experience.
- **Log Recording**: Detailed records of every write operation for easy tracking and confirmation.

## How to Contribute

We welcome all forms of contribution! You can easily participate in development through Firebase Studio:

1.  Go to [Firebase Studio](https://studio.firebase.google.com/).
2.  Click **Import Repo** in the bottom-left corner.
3.  In the **Repo URL** field, enter `https://github.com/potatosserver/WalkGo`.
4.  Name your workspace **WalkGo**.
5.  Check the **Mobile SDK Support (Flutter + Android Emulator)** option.
6.  Click **Import**.

After importing the project, you can start modifying the code. Once you're done, push your changes to your branch and open a Pull Request. We will review it as soon as possible.
