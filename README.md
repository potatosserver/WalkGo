# WalkGo
<img src="https://github.com/user-attachments/assets/61655618-1b5b-48d0-bf8e-d708ef74fd60" width="30%" alt="icon">

WalkGo 是一款專為了解決「運動時無法準確記錄步數」問題而設計的 Flutter 應用。當您進行的運動不易被手機偵測，或單純忘記攜帶手機時，WalkGo 可以幫助您補登這些遺漏的步數。它提供了一個強大且易於使用的解決方案，讓您的健康數據更完整。

## 主要功能

- **自動計步**：設定好您期望的步數和時間間隔，WalkGo 能在背景自動、穩定地寫入步數數據到您的健康應用中。
- **手動模式**：需要立即增加步數？只需一鍵，即可手動寫入您設定的步數。
- **智慧化設定**：
  - **隨機偏移**：讓每次寫入的步數在一個小的範圍內隨機波動，使數據看起來更自然。
  - **自動暫停**：設定一個步數上限，當達到目標時，服務會自動暫停，避免產生過多不必要的數據。
- **高度客製化**：您可以自由調整每次寫入的基礎步數、隨機偏移範圍、時間間隔，以及自動暫停的上限。
- **多國語言**：內建多國語言支援，包括繁體中文和英文。
- **深色模式**：支援淺色與深色模式，提供舒適的視覺體驗。
- **日誌記錄**：詳細記錄每一次的寫入操作，方便您追蹤與確認。

## 貢獻方式

我們歡迎任何形式的貢獻！您可以透過 Firebase Studio 輕鬆地參與開發：

1.  前往 [Firebase Studio](https://studio.firebase.google.com/)。
2.  點擊左下角的 **Import Repo**。
3.  在 **Repo URL** 中輸入 `https://github.com/potatosserver/WalkGo`。
4.  將您的工作區命名為 **WalkGo**。
5.  勾選 **Mobile SDK Support (Flutter + Android Emulator)** 選項。
6.  點擊 **Import**。

匯入專案後，您就可以開始修改程式碼。完成後，請將您的變更推送到您的分支，並發起一個 Pull Request，我們會盡快審核。
